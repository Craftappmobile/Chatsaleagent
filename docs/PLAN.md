# План: «Агенція з 7 ШІ-агентів» в Україні — a2auhp.tech

> **Мета:** повторити модель «власник спить — 7 ШІ-агентів працюють»: агенти самі знаходять бізнеси з поганими сайтами (або без сайту), роблять їм новий лендинг-демо, розсилають пропозиції, ведуть переписку та оформлюють оплату. Власник втручається тільки у двох випадках: велика угода або падіння відповідей нижче 12%.
>
> **Що вже є:** домен `a2auhp.tech` (куплений на Hostinger), хостинг — Vercel, репозиторій `Craftappmobile/Chatsaleagent`.

|---|---|---|
| Чек | $400/міс | **1 500–3 000 грн/міс** (~$35–75). $400 український малий бізнес масово не платитиме |

**Висновок:** система та сама, але гроші різні. Тому план має два треки:

- **Трек А — Україна (старт, тижні 1–10).** Дешево, рідна мова, швидко налагодити всю машину і отримати перших клієнтів.
- **Трек Б — експорт (з місяця 3).** Та сама система англійською для малого бізнесу США/Канади/UK, де $200–400/міс — нормальна ціна. Саме так виходить економіка «як у китайця». ФОП 3 група може отримувати валюту за експорт послуг.

Цифри з історії — це заява самого підприємця, а не перевірений звіт. Сприймаємо їх як гіпотезу, яку перевіряємо на своїх метриках.

## 1. Бізнес-модель (Трек А)

### Кому продаємо (перші 2–3 ніші)
Ніші, де є гроші, клієнти шукають в Google, а сайти зазвичай погані:
1. **Стоматології та приватні клініки** (високий чек, важливий онлайн-запис)
2. **СТО / автосервіси / шиномонтаж**
3. **Салони краси, барбершопи, косметологи**
4. Ремонт квартир, будівельні бригади, меблі на замовлення
5. Юристи, нотаріуси, бухгалтерські послуги
6. Садиби, міні-готелі (Карпати, узбережжя)

Міста: Київ, Львів, Дніпро, Одеса, Харків, далі обласні центри.

### Що продаємо — «сайт за підпискою»
| Пакет | Ціна | Що входить |
|---|---|---|
| **Старт** | 1 490 грн/міс | Лендинг, хостинг, SSL, підключення домену, форма заявки → Telegram/Viber/email, 1 правка на місяць |
| **Бізнес** | 2 990 грн/міс | До 5 сторінок, онлайн-запис, оптимізація Google Business Profile, базове SEO, аналітика, до 5 правок на місяць |
| **Про** | 5 990 грн/міс | + ШІ-чат-бот на сайті, інтеграція з CRM (KeyCRM тощо), окремі лендинги під рекламу, A/B-тести |

- **Встановлення — 0 грн**: демо вже зроблене агентами, це головний «гачок».
- Мінімальний термін — 3 місяці, або оплата за рік зі знижкою 20%.
- Домен клієнта: підключаємо його наявний або купуємо за його кошти.

### Правила втручання власника (адаптовано)
| Оригінал | Наша версія |
|---|---|
| Угода > $3 000 | Разова угода **> 100 000 грн** або підписка **> 10 000 грн/міс**, або нестандартне ТЗ (інтернет-магазин, інтеграції з 1С/CRM, багатомовність) |
| Відповіді < 12% | **Reply rate за 7 днів < 12%** (мінімум 200 надісланих) → кампанія ставиться на паузу автоматично, власнику — сповіщення в Telegram з варіантами нових текстів |
| — (додаємо) | Bounce > 3% або скарги на спам > 0,1% → **миттєва зупинка розсилки** |
| — (додаємо) | Агресивна відповідь, погрози, згадки юриста/скарги, повернення коштів → власнику |
| — (додаємо) | Агент не впевнений у класифікації відповіді (впевненість < 0,7) → черга на погодження |

## 3. Архітектура

```
                    a2auhp.tech (Vercel, Next.js)
   ┌──────────────────────────────────────────────────────────┐
   │  /            продаючий сайт агенції, ціни, оферта       │
   │  *.a2auhp.tech  → демо-сайти лідів (middleware по host)  │
   │  client.com.ua  → сайти клієнтів (той самий рендер)      │
   │  /d/[slug]      сторінка «до / після» для ліда           │
   │  /admin         панель власника: KPI, черга погоджень    │
   │  /api/webhooks  пошта, оплати, Cal.com, Telegram         │
   └───────────────┬──────────────────────────────────────────┘
                   │
   ┌───────────────▼─────────────┐    ┌────────────────────────┐
   │ Supabase (Postgres+Storage) │◀──▶│ Trigger.dev (воркери)  │
   │ ліди, аудити, сайти, листи, │    │ cron + черги, 7 агентів│
   │ угоди, KPI, стоп-лист, логи │    │ Playwright, ретраї     │
   └─────────────────────────────┘    └───────────┬────────────┘
                                                  │
              Claude API · Google Places · PageSpeed · Instantly
              WayForPay/monobank · Vercel API · Telegram Bot
```

**Ключові рішення:**
- **Одна Next.js-програма для всіх сайтів (multi-tenant).** Демо — це рядок у базі + шаблон, а не окремий деплой. Демо з’являється за секунди і майже нічого не коштує. Коли клієнт платить, його домен додається до того ж проєкту через Vercel API і рендериться той самий сайт.
- **Шаблони + JSON, а не «ШІ пише HTML з нуля».** ШІ заповнює схему (hero, послуги, ціни, відгуки, FAQ, контакти, кольори), а верстку дають перевірені шаблони ніші. Якість стабільна, правки дешеві.
- **Фонова робота — на Trigger.dev**, а не у Vercel Functions: довгі ланцюжки агентів, headless-браузер, ретраї та розклад без лімітів часу виконання.
- **Мова — TypeScript скрізь** (Next.js, агенти, воркери), офіційний SDK `@anthropic-ai/sdk`.

### Структура репозиторію (пропозиція)
```
app/
  (marketing)/        сайт a2auhp.tech: оффер, ціни, портфоліо, оферта
  sites/[slug]/       рендер демо та клієнтських сайтів
  d/[slug]/           «до / після» для ліда
  admin/              панель власника
  api/webhooks/       inbound email, оплати, Cal.com, Telegram
middleware.ts         маршрутизація за hostname (піддомени, домени клієнтів)
templates/            шаблони лендингів за нішами (React-компоненти)
agents/               7 агентів: промпти, JSON-схеми, інструменти

lib/                  supabase, claude, vercel-domains, mail, telegram, payments
supabase/migrations/  схема БД
docs/                 цей план, шаблони листів, playbook заперечень
```

## 4. Домен: Hostinger → Vercel (покроково)

Для демо на піддоменах (`salon-lviv.a2auhp.tech`) потрібен wildcard `*.a2auhp.tech`. Vercel видає SSL для wildcard **тільки якщо DNS домену керує Vercel** (метод nameservers).

1. **Vercel:** створити команду на плані **Pro** ($20/міс; безкоштовний Hobby — лише для некомерційного використання). Імпортувати репозиторій `Craftappmobile/Chatsaleagent`.
2. **Vercel → Project → Settings → Domains:** додати `a2auhp.tech`, `www.a2auhp.tech`, `*.a2auhp.tech`.
3. **Перед зміною DNS:** якщо на Hostinger є пошта для цього домену — переписати її MX/TXT-записи (SPF, DKIM), щоб відтворити їх у Vercel DNS.
4. **Hostinger hPanel → Домени → a2auhp.tech → DNS / Nameservers → Change nameservers:**
   `ns1.vercel-dns.com` та `ns2.vercel-dns.com`.
5. Почекати поширення DNS (зазвичай від кількох хвилин до 24–48 год), перевірити, що у Vercel статус доменів «Valid Configuration».
6. **Не розсилати холодні листи з `a2auhp.tech`.** Купити 2–3 схожі домени тільки для розсилки (наприклад `a2auhp-studio.com`, `geta2auhp.com`), налаштувати SPF/DKIM/DMARC і **прогрівати 14–21 день** до першої кампанії. Прогрів почати в перший же день — це найдовший етап.

> Альтернатива без зміни nameservers: A-запис `@ → 76.76.21.21` і CNAME `www → cname.vercel-dns.com` на Hostinger, а демо робити шляхами `a2auhp.tech/demo/{slug}`. Працює, але піддомен для кожного бізнесу виглядає переконливіше.

## 9. Юридичні та репутаційні правила

- **Комерційні розсилки.** Закон України «Про електронну комерцію» регулює комерційні електронні повідомлення: у листі має бути інформація про відправника і можливість відмовитися. Масова розсилка без згоди — ризик скарг і блокувань. Тому: персональні листи (не масові), відкриті бізнес-контакти, відписка в один клік, **стоп-лист назавжди**. Перед запуском — консультація юриста.
- **Персональні дані.** Контакт ФОП — це персональні дані (ЗУ «Про захист персональних даних»). Зберігаємо тільки бізнес-контакти, видаляємо на першу вимогу, політика конфіденційності на сайті.
- **Контент у демо.** Використовуємо тексти/фото бізнесу лише в демо з позначкою «демо-версія», демо без оплати видаляємо через 30 днів. Для клієнтів — тільки їхній контент, стоки або згенеровані зображення.
- **Оплата.** Найпростіше для B2B — рахунок на IBAN + акт (без ПРРО). Підписка карткою — WayForPay / LiqPay / monobank еквайринг з регулярними платежами; для карткових оплат зазвичай потрібен ПРРО (наприклад Checkbox). Уточнити з бухгалтером.
- **Документи:** публічна оферта на сайті, акти через «Вчасно» або Дія.Підпис.
- **Чесність:** листи підписані реальною людиною і брендом; агенти не видають себе за клієнтів чи інші компанії.
- **Трек Б (США):** CAN-SPAM дозволяє B2B cold email за умови фізичної адреси та відписки. ЄС (Польща, Німеччина) — значно суворіші правила для холодних листів, туди без юриста не йдемо.

## 10. KPI, які бачить Директор

| Метрика | Ціль | Дія при відхиленні |
|---|---|---|
| Reply rate (7 днів) | ≥ 12% | < 12% → пауза кампанії + власнику |
| Позитивні відповіді | ≥ 3% від надісланих | Директор пропонує новий оффер/нішу |
| Bounce rate | < 3% | > 3% → стоп розсилки |
| Скарги на спам | < 0,1% | будь-яка серія → стоп |
| Перегляди демо / надіслані | ≥ 25% | слабка тема листа → A/B |
| Конверсія відповідь → оплата | ≥ 25% | розбір заперечень, правка скриптів Менеджера |
| Вартість ШІ на нового клієнта | < 500 грн | оптимізація моделей/кешу |
| Відтік клієнтів | < 5%/міс | опитування, допродажі |
